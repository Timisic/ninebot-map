# 在本机查看骑行地图

先运行 `./scripts/setup.sh`。查看地图不需要登录九号。自动选车只读取本地 preferences.json，不读取会话令牌。

```bash
./run map
./run map --dataset /path/to/dataset.json
./run map --latest
./run map --dataset tests/fixtures/synthetic-map.json --no-open
```

`./run map` 自动打开已选车辆或唯一已有标准数据。没有可自动选择的数据时提示先采集或下载。网页没有文件导入、拖放导入或上传接口。默认地址为 `http://127.0.0.1:8765/`。指定 `--port 0` 可自动选择空闲端口，终端会显示实际地址。名称和主题按浏览器地址隔离，固定端口便于继续使用原名称。按 Ctrl-C 关闭服务。

`--latest` 读取已选车辆的本地最新标准数据。指定数据文件后，运行中的服务保留上次有效数据，并在文件更新时重新校验；原来的生成目录路径也会跟随 `prepared/latest.json`。页面每分钟及回到前台时检查更新，保留图层开关、已保存地点名称、当前选择、未保存草稿和视图。静态站点读取经过筛选的展示数据，服务端未提供 ETag 时仍会比较内容并刷新。升级前已经启动的服务需要重启一次。

全历史统计来自文件中的全部行程。地图只显示数据集允许的采样轨迹。两组次数与里程在左下与路线叠加图例合并显示。页面没有日期筛选，数据集自身声明的地图范围保持有效。没有可显示轨迹时显示空状态。

浏览器标题为 Along，顶部显示 Riding ｜ Running。点击 Running 显示“正在running中...”的小提示。顶部外观菜单可选择深色、浅色和跟随系统，默认跟随系统并响应系统外观变化。手动选择保存在此浏览器；无法使用浏览器存储时，仅本次页面有效。地图滚轮围绕指针位置缩放，滚轮和触控板连续输入可持续调整小数缩放级别，反向输入立即改变方向。拖动、全图或其他视角操作会取消未完成的滚轮动画。减少动画偏好下直接应用缩放。在线底图的最大缩放以可用瓦片为限。

## 数据更新

地图左上显示圆角刷新图标与“更新”，旁边用小字显示最近一次成功采集的月、日和时分。鼠标停在时间上可读完整日期。按钮保留 44 × 44 像素点击区域，没有永久填色面板。配置了公开更新接口的站点通过同源 `GET ./api/update` 读取状态，通过 `POST ./api/update` 提交空 JSON 对象触发已有 GitHub Actions。浏览器不持有 GitHub 或九号凭证。服务端负责所有访客共用的 12 小时间隔，前端在冷却期显示“正在Riding中...”，与 Running 提示使用同一组件。

页面在排队或运行时轮询状态并检查数据。工作流成功后，页面继续等待请求之后采集的数据。观察到新数据后，辅助技术收到“地图已更新”，页面的时间同步刷新，不增加永久成功状态行。页面保留地图位置、图层、地点选择与名称草稿。失败保留上一份有效地图。未配置接口的本地服务和纯静态站点会禁用更新按钮，并通过按钮提示说明原因。普通数据自动刷新继续有效。

## 路线、经过与终点

每条路线先绘制清晰底线，单次经过也可见。重复经过在暗色下叠加亮色，在浅色下叠加深色。线宽随缩放小幅调整，并用主题对应的衬线与底图分离。选中地点后，其他路线弱化，取消选择恢复全部路线。浅色下底图保持 OpenStreetMap 原色，深色下仅在本机调整瓦片颜色，不增加模糊滤镜；地图支持小数缩放，并开启高像素密度瓦片支持。连续缩放保留已加载瓦片，直到新层级图片到位，再由 Leaflet 回收旧层级。小数缩放期间瓦片按比例显示，清晰度受原始瓦片分辨率限制。相邻采样点相距超过 1,000 米时断开绘制，也不统计中间区域。孤立点仍可显示，但不构造补充路线。

“经过次数”使用约 200 米的方格，统计当前地图内有多少次不同的行程经过。每次行程在一个格子里只计一次，重复采样、来回经过和环线不会增加该格子的次数。线段穿过的格子也会计入，与点密度无关。鼠标移到区域或轻点地图可查看次数。

“常去地点”只取每条轨迹的最后一个观测点，不推断停留、地址、家或工作地。全部地图轨迹建立固定分组，数据刷新后通过行程成员恢复名称。列表按当前结束次数排序，显示最多前 100 处；地图默认只标出前六处，选择其他地点时显示对应标记。列表与地图标记共享顺序。地点列表默认收起。桌面展开为右侧停靠面板，小屏幕为底部面板，地图为面板留出空间。点击列表或地图针选中地点，选中地图针显示浅色圆盘与深色轮廓，并保持在其他地图针上方。点击后用三秒浅色提示和小号名称标明具体地点。再次点击同一地点保持选择和命名草稿，并重新开始提示。提示结束保留选中针与视角。重绘和同一数据集刷新不会延长原提示，减少动画偏好使用静态提示。只有“取消选择”清除选中。选择地点不会自动平移地图，“在地图中定位”才移动视角，并重新提示具体地点。点击“命名”进入编辑，关闭后重新展开面板仍保留草稿。地图针的 17 像素图形保留 44 × 44 像素点击区域。

名称存于此浏览器的 localStorage，以数据集标识、原始坐标和聚类设置隔离。旧版原始坐标道路预览保存的名称仍可读取。名称关联标注时的行程成员，不关联排名。新增数据改变锚点时，通过原成员恢复名称；多个不同名称并入同组时不自动猜测，旧名称仍在本机保留。浏览器禁用存储时，本次页面仍可编辑名称，关闭后失效。修改名称不会向服务端写入。

## 图层

右下角“图层”只有两个开关。

- “道路底图”切换 OpenStreetMap 道路预览。关闭时为无底图，打开时直接叠加原始坐标。
- “经过次数”切换约 200 米网格统计。

界面统一使用原始坐标，不执行 GCJ-02 或 BD-09 转换。开关底图不移动轨迹或改变地点分组。默认关闭底图，不请求网络瓦片。地址可使用 `#basemap=osm` 显式打开底图；旧 `crs` 参数不再改变显示方式。

数据文件中的坐标来源声明保持不变，叠加道路不代表已核实来源。开启底图只向 OpenStreetMap 请求当前视野瓦片，服务方可据此知道大致区域。路线点和本地名称不会上传。底图失败不影响路线，没有定位、反向地理编码、分析上报、远程字体或批量瓦片下载。得意黑随网页在本地提供，来源与许可证见[字体说明](design/font.md)。

## 计算约定与限制

网格采用球体半径 6,371,008.8 米的局部等距近似，经度比例固定为数据范围中心纬度的余弦。投影原点固定在全部地图点包围盒中心，图层切换不改变网格。仅接受经纬跨度分别不超过 3°、纬度在 ±75° 内的数据；跨区域与跨日期变更线数据需要预先拆分。网格不是精确道路匹配。

每个格子包含左侧和下侧边界。恰好经过角点的线段只增加前后两个内部格子，不额外计入侧边格子；线段的两个端点各计入其所属格子。重复零长度点安全。

终点分组先计算每个终点 100 米半径内的全部终点数。这个密度只计算一次，按密度从大到小、行程 ID 从小到大排序。依次将尚未分组的终点作为固定锚点，吸收半径内未分组的终点。不移动中心，不做链式合并。每个终点恰好属于一组，单个孤立终点也保留。

输入上限为 40 MB、25,000 次行程、300,000 个轨迹点、1,200 个月份。空间计算还限制 1,500,000 个行程与网格关联、4,000,000 次空间分桶与边缘点比较。超过时明确报错，保留上一份有效地图。极度密集的大文件可能在达到文件上限前触及计算上限。

服务仅绑定 `127.0.0.1`，使用固定资源白名单和启动时读取的单份数据快照，不提供目录浏览。输入必须通过统计与关联验证，浏览器还会验证空间边界。服务拒绝异常 Host、跨站 Origin、跨站浏览器请求和写入方法。

## 开发验证

```bash
.venv/bin/python -m unittest discover -s tests -q
npm ci
npm run verify:doctor
npm run verify:smoke
npm run verify
```

浏览器验证默认使用本机安装的 Chrome。CI 使用 `PLAYWRIGHT_CHANNEL=chromium` 和 Playwright 管理的 Chromium。`npm run verify` 保存分项日志和结果，刷新验收另存动作记录与前后截图，并确认自己启动的服务已关闭。证据默认保存在忽略目录 `work/verification/`，也可用 `--output` 指定目录。

可用 `npm run verify -- --suite map`、`--suite wheel` 或 `--suite refresh` 验证单项。脚本使用合成 fixture 和独立随机端口，覆盖桌面、小屏幕、活动导航、系统及手动主题、名称持久化、公开更新状态、无效数据刷新、底图开关、原始坐标不变、主题和缩放。网络瓦片在测试中模拟提供，滚轮输入也是合成事件；这些检查不验证真实瓦片可用性或实体触控板手感。Agent 的具体操作与完成条件见[项目验证技能](../.agents/skills/verify-ninebot-map/SKILL.md)。

本轮界面参考 [Apple 地图](https://www.apple.com.cn/maps/) 的地图优先与控件分组，以及 [Mapbox Light](https://www.mapbox.com/maps/light) 的背景与叠加数据层级。它们仅为视觉参考，运行时没有增加服务或依赖。
