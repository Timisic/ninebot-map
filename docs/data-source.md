# 数据来源与协议

本项目读取用户本人九号账号的云端数据，非九号官方项目。

- 认证与加密代码改编自 MIT 项目 [ninebot-recon](https://github.com/kxn/ninebot-recon)，基于修订 `a46124d6290179554e1688c01384a7f4116ac96a`。原版权声明保留在 `nbmap/vendor/LICENSE`。
- 行程字段解释参考 [ninebot-desktop](https://github.com/cixiangtao/ninebot-desktop)，未复制其桌面界面代码。
- ninecli 曾用于开发期独立对照，不属于本项目运行依赖。

本地适配包括成功码处理、gzip 响应、会话刷新、只读分页、私密存储及覆盖检查。正常请求使用九号的认证、业务登录、车辆和行程域名；没有车辆控制功能。

云端多点轨迹通常仅限最近约 180 天，更早记录可能只返回简化坐标及汇总。时间窗口依据响应标记和有限的只读对照，不代表后台原始数据已被永久删除。已保存到本地的采样不会自动删除。

仓库包含程序、文档、合成测试和 README 轨迹图片。原始行程档案与会话保存在用户自己的本机或私有同步仓库。
